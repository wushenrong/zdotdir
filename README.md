# zdotdir

My zsh configurations based on <https://github.com/getantidote/zdotdir>,
<https://github.com/mattmc3/zephyr>, <https://github.com/mattmc3/z1>, using
<https://github.com/mattmc3/zsh_unplugged>.

You will need

- bat
- bsdtar
- btop
- delta
- duf
- eza
- fastfetch
- fd
- fzf
- gdu
- hexyl
- procs
- ripgrep
- vivid
- wl-clipboard
- zoxide
